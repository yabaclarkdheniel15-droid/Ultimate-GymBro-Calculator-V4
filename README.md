# Weekly Fitness Tracker and Gym Recommendation System

*A P4E-inspired intermediate Python project that combines:*
Fitness tracking,
Nutrition analysis,
Gym programming,
Budget monitoring,
Iteration and function-based coding.


*Features:*
Weekly calorie surplus/deficit analysis,
Protein intake tracking,
Weekly food budget monitoring,
Gym split recommendations,
Muscle group frequency analysis,
Past week training evaluation,
Body type-based food recommendations,
Recovery and nutrition warnings,
Body Types Supported.


*The program explains body types before asking the user:*


Ectomorph — Lean body type, struggles to gain weight

Mesomorph — Athletic body type, gains muscle easily

Endomorph — Gains weight easily, slower metabolism


*Gym Features:*
Suggested Gym Splits,
Full Body Split,
Upper-Lower Split,
Push-Pull-Legs,
Advanced Push-Pull-Legs.


*Muscle Groups Tracked:*
Chest,
Back,
Legs,
Shoulders,
Arms.


*Programming Concepts Used:*
Functions,
Lists,
Dictionaries,
Iteration (for loops),
Conditional statements,
User input handling,
Modular programming.
